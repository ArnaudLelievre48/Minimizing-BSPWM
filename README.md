# Minimizing-BSPWM
Utility tool to make minizing windows possible in BSPWM like it is on non-tiliing WM

## Installation and usage

**First you will need to be using bspwm, but I am sure the way my scripts work, that the adaptation for another tiling WM will be easy enough.**

how it work, and how to install it :
- in the *bspwm* config file `bspwmrc` you have to add a desktop called `"hidden"` with something that look like this : `bspc monitor eDP-1 -d 1 2 3 4 hidden &`
- in `sxhkdrc` the binds for switching desktop or moving windows around will need to be adapted to skip that `"hidden"` desktop. I recommend doing something like 
```
NEXT_DESKTOP=$(bspc query -D -d next.local --names); \
	if [ "$NEXT_DESKTOP" != "hidden" ]; then \
		bspc desktop -f next.local; \
	else \
		bspc desktop -f next.local; \
		bspc desktop -f next.local; \
	fi
```
of course you will need to do this for previous desktop as well and for moving windows from one desktop to another...
- Bind the execution of `minimize.sh` on your `sxhkdrc`. `minimize.sh` minimizes the focused window by putting it into the `"hidden"` desktop with an animation made by moving and resizing the window  ** *Note that the animation will thus change based on your picom animations* **. `minimize.sh` also takes a screenshot of the window with `maim` and saves it in `thumbnails`.
- Bind the execution of `restore-menu.sh` on your `sxhkdrc`. `restore-menu.sh` spawns a menu thanks to the screenshots in `thumbnails` which allows you chose which window id will be call with `restore.sh`. `restore.sh` will then play the animation, remove the screenshot from `thumbnails` and of course move the window back to your focused desktop.
